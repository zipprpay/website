How it works

From agent decision to money received

Agent initiates

Your agent calls Zippr with a customer ID and an amount — over the REST API or an x402 payment request.

Funds held in non-custodial escrow

The amount is locked in a non-custodial escrow until the recipient claims the funds. Zippr never takes custody of funds.

Human gets paid

Zippr generates a voucher code and unique redeem link. Send the voucher code and/or link to the recipient.

Flexible payout

The recipient receives payout funds in the most convenient way - bank transfer, crypto, digital wallet, prepaid card, gift card or cash pickup.
